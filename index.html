What 0 is

0 is the completed set: the turnover where one set is full and the next count begins. In this converter it is never a step you count and never a first item: the quantity starts at 00, the ground, and the count starts at 01.

Every new thing brings its not-thing with it at the same moment, and the pair shows the boundary: 1 comes with 0, a state with its ground, a set with its completion. 0 is that boundary, so the first value is written 01, never a bare 0 or a bare 1: 01 Hz, 01 bits. On every dial the ground is the dashed slot at the top.

Where this number keeps it, changes it or loses it

The amount never changes between translations. What changes is the 0: a translation can keep it, give it another job, or drop it. The rows on screen for the current number come first.

                About

                Machines count from 0, people count from 1, and small things get lost in between: a dropped zero, an off-by-one, a misread digit. Lost N' Translator shows one number as bits, light, sound and symbol at once, so you can see where the meaning slips.

                Use it as a number base converter (base 2, 4, 10, 12 and 16, from 00 to 999), as a text to binary and ASCII converter, or to turn binary into music: type your name to see each letter in binary and hear its ASCII codes as piano notes and a sung voice.
